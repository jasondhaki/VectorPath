# BUG-W01-004 — BD residential-hall addresses and dotted "Dist." rural addresses are not minimized

- Severity: **Medium**. Bangladesh is first-class (D06), and hall addresses are common in BD student and graduate CVs. Fix before U19b, or record an owner-approved limitation.
- Unit / suspected owner: U18 · vp-domain · `lib/domain/redaction/redact.ts`.
- Found by: vp-qa during BUG-W01-001 round-3 re-verification, 2026-10-21.

## Repro (fictional strings)

`redactContacts(s).text` returns each input **unchanged**:

| Input | Note |
|---|---|
| `Room 214, Bijoy Ekattor Hall, Dhaka 1000` | BD hall room with a 4-digit BD postcode |
| `Hall: Shahidullah Hall, University of Dhaka` | labelled residential hall |
| `Room 4, Hall 2, BUET, Dhaka 1000` | hall room |
| `Village Rampur, Dist. Sitapur, UP 261001` | dotted `Dist.` plus a 2-letter state; `Dist:` with a colon is already removed |

Removed correctly, for contrast:
- `House 5, Road 2, Rajshahi 6000`
- `House 23, Road 7, Gulshan 1, Dhaka 1212`
- `Village Rampur, Dist: Sitapur`
- `Vill: Charpara, P.O: Kalihati, Dist: Tangail`

## Expected / actual

- Expected (§6.2, I07): residential address lines in supported countries are minimized.
- Actual: the hall and dotted-district forms above are persisted.

## Suggested direction

- **BD hall addresses:** treat `Room N` together with `… Hall`, or a `Hall:` label line, as an address, along with a BD city + 4-digit postcode at line end (`Dhaka 1000`).
- **Dotted district:** accept `Dist.` / `P.O.` with a trailing dot followed by a place name. Accept a 2-letter Indian state abbreviation before a PIN.
- **Experience lines to keep:** for example `Hall committee member, 2019` and `Organised Room 214 workshop`.
