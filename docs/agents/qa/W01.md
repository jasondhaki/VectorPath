## 5. QA-owned changes

- `playwright.config.ts`: three viewport projects (`w375`, `w1024`, `w1440`) with per-project `testMatch`. The isolated server and network block are unchanged.
- `tests/e2e/fixtures.ts`:
  - `MISSING_PATH`, `must()` and `expectNoHorizontalOverflow()`.
  - `runAxe` / `runAxeFull`, which inject `axe-core/axe.min.js` from node_modules. It is a **transitive** dependency (4.14.0); a missing package fails the test rather than skipping it.
- New specs: `tests/e2e/shell.spec.ts`, `mobile.spec.ts`, `rail.spec.ts` and `wide.spec.ts`. `scaffold.spec.ts` is unchanged and runs at 375 and 1440.
- `scripts/check-tokens.mjs`, per the frontend REQUEST:
  - **New rule:** literal colours in style props and SVG attributes, such as `color: "red"` or `fill="black"`. Allowed values are `var()`, `currentColor`, `transparent`, `inherit`, `initial`, `unset` and `none`.
  - **White/black and default-palette rules** now cover `fill`, `stroke`, `outline`, `ring`, `ring-offset`, `accent`, `caret`, `decoration`, `placeholder`, `divide` and the side variants of `border-*`.
  - **Colour functions are caught anywhere a letter or hyphen does not precede them.** This includes `_rgb(` inside brackets, plus `hwb`, `lab`, `lch`, `oklab`, `color()` and `color-mix()`.
  - **Arbitrary brackets** now catch named CSS colours, such as `bg-[red]`.
- `tests/unit/scripts/checkers.test.ts`: 5 token tests (positive and negative) and 2 `require-test-db` tests that run in an empty temp directory, so no real `.env.local` is read.
- `scripts/require-test-db.mjs` (R3-10 follow-up): loads `.env.local` via `process.loadEnvFile`. It never overrides variables that are already set and prints nothing. It still exits 1 with `BLOCKED:` when the variable is absent everywhere. Isolation stays enforced by the harness guard.
