## Spec-silent decisions (handoff §Decisions)

1. **Dedup keeps the highest required level.** The spec is silent on this. The choice is conservative and has little practical effect today, but it is still a scoring rule, so it should be recorded (F3).
2. **Neighbor edges count in either direction, and ties go to the lowest ID.** The spec is silent. Similarity is symmetric, and the tie rule only changes the `neighborVia` label, not the value. Safe.
3. **Unknown years give level 0.** This is the literal reading of "no time-derived credit" (§7.1) and is conservative. Safe.
4. **Reach rejects an inconsistent W and treats a scale mismatch as unknown.** §7.3 says "only apply when both use the verified same source scale". Non-integer zones throw. Safe.
5. **Demand ages and exclusions.** The 30-day and 5-year limits come from §4.2:94. Nulls are excluded, which follows "missing is not zero". `cohortSize` is disclosed when N <10, which follows "disclose sample size". The forecast needs sector data, which follows "no sector data means M is unavailable". Cohort comparability is left to the caller (U15). Safe, but see F2.
6. **Ranking choices.** Filters apply before diversity, unknown-sector roles are excluded by a sector filter, and held roles bypass filters. The spec is silent; the choices are safe (F8). Relaxing only when the cap is the cause is exactly what §7.5 says.

None of these decisions adds a factor, makes a probability claim or turns missing data into zero. Only F3 needs a decision record.
