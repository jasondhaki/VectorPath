### Fresh adversarial traces

- `"01712  345678"` (two spaces inside one number): `chains` rejects `"  "` (redact.ts:104 `!/\s\s/`), giving groups of 5 and 6 digits, each under 9. **Not redacted.** Round 1 caught this form, so the fix introduced a regression. Same for `"017 1234  5678"` and `"+880  1712  345678"` (the 10-digit tail only is caught when its groups are single-spaced).
- `"+44 20 7946 2001"`: the chain is 12 digits and international, so it passes. The trailing-year trim (redact.ts:149) then checks `isPhoneRun(+44 20 7946)`, which is 8 digits and still international-valid, so `2001` is trimmed and **the last four digits stay visible**. The trim is safe for non-international runs, where the 9-digit minimum stops it (`"020 7946 2001"`, `"415 555 2019"`). It is not safe for `+`-prefixed runs whose last group falls in 1900–2099.
- `"JaneDoe.dev"` / `"Portfolio: Janedoe.me"`: BARE_DOMAIN is lowercase-only and its lookbehind blocks starting mid-word, so these are **kept**.
- `"District-level coordinator for a health project"`, `"Union-level survey"`, `"Thana-level training"`: BD_LABEL `dist(?:rict)?\s*[:\-]` matches `District-`, and the line starts with a label, so the **whole experience line is removed** (redact.ts:185, 193).
- Kept, correct: `"Python 3.11 and ISO 9001:2015"`, `"GPA 3.75 out of 4.00"`, `"9:00 – 17:00 (8 hrs)"`, `"12/03/2019"`, `"Since 2019 01712345678"` (year kept, phone removed).
- Removed, correct: `"(+880) 1712-345678"` (separator `") "` chains, 13 digits international; becomes `"([phone removed]"`), `"02-9123456 2019"` (trailing year trimmed), `"Tel+8801712345678"` (non-international path, 13 digits).
- Linear bound: the scan is capped at 15 groups per start (redact.ts:132), and the test at :183-188 covers it.

### Stated trade-off (9–15-digit separated runs are redacted, including some IDs)

Judged against §6.2:156 ("Remove … phones … Redaction is imperfect") and I07: the spec sets no precision target and requires minimization, so over-redaction is the permitted direction. It also catches national-ID-like numbers, which helps privacy. The cost is lost evidence, for example `"ISO 9001 14001"` (9 digits, no year) becomes `[phone removed]`, so a certification quote over it cannot be verified. **Accepted.** Record it as a known limitation for U19b and the methodology page (U26).
